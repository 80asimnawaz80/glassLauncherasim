GlassLauncher - Android TV launcher (Kotlin + Compose for TV)
1. Open this folder in Android Studio (let it sync / update versions if asked).
2. Run on an Android TV emulator or a real TV box (USB/Wi-Fi ADB).
3. Press HOME and choose "Glass Launcher" -> Always.
Store: "Play Store" tile opens the TV Play Store; "Find & install" searches it; "Install APK link" downloads + opens the installer (needs "Install unknown apps" allowed).
Hold OK on an app for Open / App info / Uninstall. The app list refreshes automatically after any install or removal.
Speed notes: no blur effects, apps load on a background thread, one static gradient, only focus-scale animation, release build is minified.
